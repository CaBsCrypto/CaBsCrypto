# Scope: Milestone 3 — Bento Grid Showcase, Project Modals & Tech Stack Matrix

## Architecture & Responsibilities
- `js/bento.js`: Responsive 12-column Bento Grid for Web3/Crypto/Dev projects with hover states, status badges (Mainnet, Audited), tech stack tags, hero vs standard cards, and project detail modal trigger.
- Project Detail Modal: Backdrop blur overlay, body scroll lock, focus trap, complete project metadata (description, features, architecture, live demo link, GitHub link), close button with Esc & click-outside listeners.
- `js/matrix.js`: Tech Stack Matrix grouping skills into 4 categories (Blockchain/Web3, Frontend, Backend & CLI, DevOps), animated neon progress bars (0-100%), hover tooltips, and interactive category filter tabs.
